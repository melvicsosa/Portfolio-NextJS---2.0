This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Project Overview

Personal portfolio for Melvic Sosa built with Next.js 15, React 19, Tailwind CSS, and Framer Motion. It showcases recent work, an interactive 3D globe experience powered by `three`/`three-globe`, a theme-aware interface, and quick access to the latest resume download.

## Recent Highlights

Recent work focused on stabilising the 3D globe lifecycle under React 19, aligning the Three.js dependency stack, and polishing the resume CTA in the footer.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Deploy on Netlify

Deploy by connecting the repository to [Netlify](https://app.netlify.com/) or by using the Netlify CLI:

```bash
npm install -g netlify-cli
netlify init
netlify deploy --build
```

Refer to Netlify’s [Next.js deployment guide](https://docs.netlify.com/integrations/frameworks/next-js/overview/) for configuration details.
